## 2. 打包经验补充

[`fnos-packaging-notes.md`](fnos-packaging-notes.md) 记录了官方文档之外、实际打包中必须注意的经验：

- fnOS **不托管应用进程**：上游依赖 systemd 按退出码重启的契约，需要用启动器自带 supervisor；
- 媒体/文件路径权限：应用用户对 `/vol` 目录“能穿越、不能列目录”，浏览失败但手填完整路径可行；
- 工程实践：按架构拆包、只用官方字段、`fnpack` 行为、Windows/WSL 的 LF 与可执行位、卸载清理；
- 供应链与校验：固定 `fnpack` 哈希、校验上游产物、打包后契约校验；
- 排错方法与日志位置，以及一次真实的 `APP_CRASH` 案例时间线；
- 打包/发布检查清单。
